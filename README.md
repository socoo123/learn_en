# 英语学习笔记本 · English Reader

一个 React + Vite 做的中英对照英语学习网站。带年/月/日树形归档、可收起的中英对照、核心词高亮联动、紧凑生词表、语法详解、以及课后练习（选择 / 填空 / 阅读理解）。

---

## 学习者画像（Claude 每次会话都会读）

- **背景**：外企工作约 6 年
- **现状**：能听懂基本英语会议，但多数时候需要英文字幕；口语较弱；**词汇量偏弱**
- **目标**：把"能看懂"提升到"能用出来"
- **偏好**：浅色主题、高对比、科技感界面

> 📌 **补词约定**：阅读时遇到"不认识、但 Claude 没收进生词表"的词，直接贴给它，它会补进对应那一课的生词本，并把这些词作为评估你真实水平的依据。

> 完整的工作流与规则见 `CLAUDE.md`。

## 一、怎么打开

需要先装依赖（只第一次），之后每次启动开发服务器即可：

```bash
cd /Users/zy/ai_learn/learn_en
npm install        # 只第一次需要
npm run dev        # 启动，浏览器自动打开 http://127.0.0.1:5900/
```

> 启动后**保持终端开着**就行。我用 Claude 往数据文件里加新课时，网页会**自动刷新**，你不用做任何事。
> 想停就按 `Ctrl + C`。

如果想要一个可以双击、可部署的静态版本：
```bash
npm run build      # 产物在 dist/，把它放到任意静态服务器即可
```

## 二、界面说明

| 区域 | 作用 |
|------|------|
| **左侧栏** | 按 **年 → 月 → 日** 折叠展开（默认展开当前年月），可搜索标题/单词/日期。一周学一两篇也不会显得空 |
| **中间阅读区** | 顶部工具栏：`中文 展开/收起`、`☀️/🌙` 主题、上一课/下一课（也可用键盘 `←` `→`） |
| **正文** | 每段默认**只显示英文**，点「查看中文」单独展开该段翻译（带动画）；或用顶部按钮一键展开全部 |
| **右侧标注栏** | 本课核心词 + 核心语法。点核心词 → 正文里对应处**高亮闪烁**并滚动定位；点正文高亮词 → 右侧卡片也闪（双向联动） |
| **生词表** | **紧凑版**，每行一个词；点「例句」展开该词的例句 |
| **语法详解 / 难句分析** | 新概念风格的讲解 |
| **课后练习** | 选择题、填空题、阅读理解；做完即时判对错、给解析，顶部显示已答/正确数 |

## 三、怎么添加新材料（核心工作流）

把材料交给 Claude（我），我来翻译、提取核心词和语法、出练习题、存档。三种方式任选：

- **方式 A**：在对话里直接贴一段英文
- **方式 B**：给我一个文本文件路径，如 `帮我分析 /Users/.../notes.txt`
- **方式 C**：给我一个 PDF 路径，如 `帮我分析 /Users/.../article.pdf`（扫描件图片型 PDF 效果不好，到时我会说）

### 我会做什么
1. **翻译**：逐句中英对照
2. **挑核心词/短语**：放进右侧标注栏（最值得先记的 5~8 个）
3. **生词表**：底部完整词表（音标 / 词性 / 释义 / 例句）
4. **语法 + 难句分析**：拎出值得讲的点
5. **出练习题**：3~5 道选择/填空/阅读理解
6. **存档**：按 `日期 + 摘要标题` 写入 `src/data/lessons.js`，网页自动刷新出现

> 不指定日期我就用**今天**，标题我自动起一个中文摘要（页面上会以 `YYYY-MM-DD　标题` 显示）。

## 四、文件结构

```
learn_en/
├── index.html                 # Vite 入口
├── package.json / vite.config.js
├── src/
│   ├── main.jsx               # React 入口
│   ├── App.jsx                # 整体布局 + 状态/动画
│   ├── styles.css             # 全部样式 + 深浅色主题
│   ├── data/
│   │   └── lessons.js         # ← 所有课程数据（我往这里加）
│   └── components/
│       ├── Sidebar.jsx        # 年/月/日 树形侧栏
│       ├── LessonView.jsx     # 中间阅读区
│       ├── Passage.jsx        # 中英对照 + 高亮联动
│       ├── Annotations.jsx    # 右侧核心词/语法
│       ├── VocabTable.jsx     # 紧凑生词表
│       ├── Grammar.jsx        # 语法 + 难句
│       └── Quiz.jsx           # 课后练习
└── README.md
```

每篇课程在 `src/data/lessons.js` 里是一个对象，主要字段：

| 字段 | 说明 |
|------|------|
| `id` / `date` | 唯一标识 / `YYYY-MM-DD`（标题自动以它开头） |
| `title` | 中文摘要标题 |
| `source` / `tags` | （可选）来源 / 标签 |
| `passage` | 中英对照正文 `[{ en, zh }]` |
| `core` | 右侧标注栏 `{ words:[…], grammar:[…] }` |
| `vocab` | 底部生词表 `[{ w, phon, pos, def, ex_en, ex_zh }]` |
| `grammar` | 底部语法详解 `[{ t, pattern, rule, examples }]` |
| `sentences` | （可选）难句分析 `[{ en, zh, analysis }]` |
| `quiz` | （可选）练习题 `[{ type, tag, q, options?, answer, explain }]` |

`quiz` 的 `type`：`"choice"`（选择/阅读理解）或 `"fill"`（填空，用 `____` 标空）。

> 这些字段你不用记，给材料就行，我按结构填好。
